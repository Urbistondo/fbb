# Pump Condition Workout Planner

A polished single-page web app for managing the "Pump Condition (4x Scaled, v2)" training block. The UI presents weekly priorities, strength progressions, conditioning prescriptions, and four structured training day templates. Each movement card can be checked off to track progress, store set-by-set logs (weight, reps, RPE, and notes), and completion data persists locally via `localStorage`.

## Getting started

Open `index.html` in any modern browser to explore the planner. No build tools or dependencies are required.
